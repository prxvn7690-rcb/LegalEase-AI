# LegalEase

LegalEase is an AI-powered legal document generator built using Python, FastAPI, Streamlit and Google Gemini.

## Features

- Generate legal document drafts using AI
- Support multiple document types
- Edit generated documents
- Preview generated documents
- Download documents as TXT
- Download documents as DOCX
- Download documents as PDF
- FastAPI backend
- Streamlit frontend

## Technologies

- Python 3.10+
- FastAPI
- Streamlit
- Google Gemini
- python-docx
- FPDF
- Pydantic
